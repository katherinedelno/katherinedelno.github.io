{%- comment -%} Feedback form. Renders one of the forms described in _data/feedback.yml and posts it straight to the matching Google Form. The mechanism is the one the signup block already uses: a normal form post aimed at a hidden iframe, so the browser never navigates, Google never appears, and the visitor sees our own confirmation. No fetch, no CORS, no API key. If scripting is off it still posts; the visitor simply does not get the inline thank-you. Usage: {% include feedback-form.html form="parent" %} {% include feedback-form.html form="student" done="..." %} The only required parameter is `form`, which must name a top-level key in _data/feedback.yml. Everything else about the form lives in that file. One thing to keep in mind when editing the data file: Google validates the submitted value of a choice question against its own option list and rejects anything else. A rejection is invisible here, because the iframe's response is same-origin-blocked. So the option strings in the data file have to match Google's exactly, character for character. {%- endcomment -%} {%- assign fb = site.data.feedback[include.form] -%} {%- if fb == nil -%}
