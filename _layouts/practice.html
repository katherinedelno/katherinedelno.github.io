The toggle buttons are generated below rather than written by hand, so the source of a practice page stays readable markdown and an author never has to keep a button, an id, and an aria-controls attribute in sync. 2. Those blocks start on the page, positioned off-screen, and are hidden only after MathJax reports it has finished. MathJax measures glyph boxes while it typesets, and anything it typesets inside a display:none container comes back with zero widths, so a solution revealed later would render collapsed.
